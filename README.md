# omzthemes

Custom [oh-my-zsh](https://ohmyz.sh) themes.

## acaSimple

The default `robbyrussell` theme, but showing the full path from `~`
instead of only the current folder name.

```
➜  ~/GitHub/omzthemes git:(main) ✗
```

### Install

```sh
ln -s "$PWD/acaSimple.zsh-theme" ~/.oh-my-zsh/custom/themes/
```

Then in `~/.zshrc`:

```sh
ZSH_THEME="acaSimple"
```
